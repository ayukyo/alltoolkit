# Number to Words Utils

A comprehensive Python utility for converting numbers to their word representation in multiple languages. **Zero external dependencies** - uses only Python standard library.

## Features

- **Multiple Languages**: English, Chinese, Japanese, Korean, Spanish, French, German
- **Integers**: Convert any integer up to 10³⁶ to words
- **Decimals**: Convert decimal numbers with precise digit-by-digit conversion
- **Currency**: Format amounts as currency words (full support for English and Chinese)
- **Ordinals**: Convert to ordinal form (first, second, third, 第X, etc.)
- **Multiple Input Types**: Accepts int, float, str, and Decimal

## Installation

No installation needed - just copy the module to your project.

## Quick Start

```python
from number_to_words_utils import number_to_words, number_to_currency_words, number_to_ordinal_words

# Basic conversion
print(number_to_words(42))  # "forty-two"
print(number_to_words(1234))  # "one thousand two hundred and thirty-four"

# Multi-language support
print(number_to_words(42, lang="zh"))  # "四十二"
print(number_to_words(42, lang="ja"))  # "四十二"
print(number_to_words(42, lang="ko"))  # "사십이"
print(number_to_words(42, lang="es"))  # "cuarenta y dos"
print(number_to_words(42, lang="fr"))  # "quarante-deux"
print(number_to_words(42, lang="de"))  # "zweiundvierzig"

# Currency
print(number_to_currency_words(42.50))  # "forty-two dollars and fifty cents"
print(number_to_currency_words(100.01, lang="zh"))  # "壹佰元壹分"

# Ordinals
print(number_to_ordinal_words(1))  # "first"
print(number_to_ordinal_words(21))  # "twenty-first"
print(number_to_ordinal_words(5, lang="zh"))  # "第五"
```

## API Reference

### `number_to_words(num, lang="en", ordinal=False)`

Convert a number to its word representation.

**Parameters:**
- `num` (int | float | str | Decimal): The number to convert
- `lang` (str): Language code (default: "en")
- `ordinal` (bool): Return ordinal form if True

**Returns:** str - The number in words

**Raises:** ValueError - If number is invalid or too large

### `number_to_currency_words(num, lang="en", currency=None)`

Convert a number to currency words.

**Parameters:**
- `num` (int | float | str | Decimal): The amount to convert
- `lang` (str): Language code (default: "en")
- `currency` (str | None): Optional currency code (future expansion)

**Returns:** str - The amount in currency words

### `number_to_ordinal_words(num, lang="en")`

Convert a number to ordinal words.

**Parameters:**
- `num` (int): The number to convert (must be integer)
- `lang` (str): Language code (default: "en")

**Returns:** str - The ordinal in words

### `get_supported_languages()`

Return list of supported language codes.

## Examples

```python
# Large numbers
number_to_words(1000000000)  # "one billion"
number_to_words(1000000000000)  # "one trillion"

# Negative numbers
number_to_words(-42)  # "negative forty-two"

# Decimals
number_to_words(3.14159)  # "three point one four one five nine"

# Chinese with scales
number_to_words(100000000, lang="zh")  # "一亿"

# Different input types
from decimal import Decimal
number_to_words(42)           # int
number_to_words(42.0)        # float
number_to_words("42")        # str
number_to_words(Decimal(42)) # Decimal
```
